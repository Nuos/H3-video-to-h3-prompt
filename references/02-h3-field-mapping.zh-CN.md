## 概念说明

“字段映射”是把观察到的人物、环境、动作、摄影、剪辑与声音证据分配到指定字段，避免不同层次的信息互相混淆。时间戳标记可观察的状态变化；首个 `[Shot 1]` 只描述开场状态。首帧、尾帧及全参考模式对视觉信息的约束不同，因此字段数量与组装方式也不同。

# 02 — 观察 → H3 字段映射与组装骨架（T2VA / I2VA / FL2VA / L2VA）

> Ref2VA 全参考模式走另一套六段式，见 `shot-syntax.md`。本文件用于无参考图或仅首/尾帧参考的 14 字段式。

## 1. 字段顺序（顺序不可换；✓ 必填，○ 条件必填）

| # | 字段 | 必选 | 装什么（观察来源） |
|---|---|---|---|
| 1 | `subject_definitions` | ✓ | 每个可见/画外角色：年龄感、发型面部、全套服装、鞋袜手套、手持剧情道具、静态佩戴道具、职能；画幅 |
| 2 | `environment_definition` | ○ | 空间、建筑、地面、背景物件、静态载具、氛围与排除项（I2VA 首帧锁定时省略） |
| 3 | `lighting_definition` | ○ | 主光方向/软硬/色温、环境补光、阴影、湿反/高光、噪点、恒常性（I2VA 首帧锁定时省略） |
| 4 | `visual_anchor` | I2VA | 仅首帧锚定模式 |
| 5 | `audio` | 复用音频时 | 提供的音频标 fully_copy |
| 6 | `integrated_multimodal_description` | ✓ | 一句话结构前提 + N 个节拍的效果兑现 + [Shot 1] 开场态（无时间戳）+ 严格递增时间戳事件链，动作处内嵌同期声 |
| 7 | `camera_direction` | ✓ | 机位/视角/景别/基线晃动；每次运镜类型+幅度+速度+**动机**；禁用运镜清单 |
| 8 | `editing` | ✓ | 切换策略；每个定格/转场/特效的入点、时长、叠加配方、回到实拍方式；N 个节拍的节奏 |
| 9 | `performance` | ✓ | 逐角色情绪弧、反差、表情约束、夸张只允许出现在哪 |
| 10 | `body_mechanics` | ✓ | 蓄力规则、力传导链、喝/喷/被打动力学、双脚扎根 |
| 11 | `costume_hair_physics` | ○ | 发型/面料/眼镜/裙摆/面罩的滞后摆动、湿身演化、逐渐落定 |
| 12 | `negative_constraints` | ✓ | 聚焦排除：人数/道具/风格化/运镜/剪辑/文字/漂移 |
| 13 | `overall_soundscape` | ✓ | 环境底噪 + 按时间同期声清单 + 定格特效音 + 录音质感 |
| 14 | `non_diegetic_music` | ✓ | fully_copy ／目标音乐设计 ／明确静音，三选一 |

## 2. 时间戳纪律

1. `[Shot 1]` 永远无时间戳，只写开场状态。
2. 其后严格递增；14 字段式可用一位小数 `[00:09.8]`，Ref2VA 用两位 `00:09.80`。
3. 只在真实状态变化处打时间戳：动作发起、受力、镜头动机起点、声音事件、剪辑点。禁止抒情式时间戳。
4. 事件写法：`[时间] 触发 → 发起 → 扩张 → 重音 → 回收`，句中内嵌同期声（"伴随一声轻微的塑料咔哒声"、"能听见倾倒液体的声音"）。
5. 相邻事件用残余动量衔接，禁止中性姿势复位。

## 3. 英文组装骨架（直接套；以下为中文全译）

```text
subject_definitions: <Subject 1> ... ; <Subject 2> ... ; <Subject N / off-camera actor>（画外行动者）绝不完整出镜：[可见部位/控制物件/每次入画职能]。竖屏/横屏 X:Y。

environment_definition: [空间、建筑、地面、背景物件、停放不动的道具、氛围、明确排除项]。

lighting_definition: [主光方向+光质+色温、环境光/补光、阴影、湿润表面反光/镜面高光表现、颗粒噪点、恒常性]。

integrated_multimodal_description: [一句话：结构前提 + N 个节拍的效果兑现 + 材料规则]。[Shot 1] [开场状态，不加时间戳，构图 + 每个主体的状态 + 前景/背景锚点]。[00:00.5] 触发→动作→扩张→重音→回收，同时内嵌同期声。... [结束时间戳] 结束状态。

camera_direction: [视点/持机者、景别、角度、基线晃动]；[区间] 运镜类型，采用[小/中/大]幅度、[慢/中/快]速度，由[身体动作/事件]提供动机；...；明确列出禁止环绕/禁止变焦的清单。

editing: [切镜策略]；每个有意设计的特效：入点、时长、叠加配方、快速恢复实拍；N 个节拍的节奏；明确不允许的内容。

performance: [逐角色的情绪弧]；反差设计；允许/禁止夸张的地方；按适用情形禁止摆拍式表情 / 始终微笑 / 对口型。

body_mechanics: [每次释放前先蓄力]；力传导链；饮水动力过程为抬臂→后仰→吞咽→放低；双脚着地，不悬浮。

costume_hair_physics: [逐角色的头发滞后摆动与湿身演化]；[面料重量、颜色变深并贴身]；[眼镜滑动/起雾；面罩阻力]；任何物件都不得独立于相应作用自行运动。

negative_constraints: [聚焦清单：不增加人物，不添加 X 以外的道具，不更换服装，不发生风格漂移，不使用被禁止的运镜，不进行普通切镜，无字幕/水印，无血液，无特效残留，不在指定节拍外定格，不改变身份]。

overall_soundscape: [环境声底层]；按顺序列出同期声提示“在 X.Xs 时……”；每次定格的后期音效；说明采用未经精修的现场录音质感。

non_diegetic_music: [fully_copy <Audio N>.] / [目标音乐规格] / [没有叙事外音乐。全程明确保持音乐层静音；……]。
```

## 4. 三层声音分离速查

| 声音类型 | 例子 | 唯一允许字段 |
|---|---|---|
| 动作同期声 | 吞咽、面罩咔哒、喷水、呛咳、脚步 | 内嵌进 `integrated_multimodal_description` 对应动作句 |
| 环境/特效总览 | 夜巷底噪、怠速、风、定格特效音序列 | `overall_soundscape` |
| 音乐层 | BGM（背景音乐）、配乐、歌曲 | 只在 `non_diegetic_music`；无乐则明确静音 / N/A |

## 5. I2VA / FL2VA / L2VA 调整

- **I2VA 首帧锚定**：开头加 `对于目标视频，在目标视频的 0.00 秒处，完整参考 <Picture 1>（来自 [Shot 1]）。`；加 `visual_anchor`；省略 environment/lighting（环境/照明）文本字段；subject（主体）以图为唯一视觉权威，只留极短身份锚点（轮廓+运动结构+整体色调）。
- **FL2VA**：补首帧状态 → 可观察的中间变化 → 收敛到尾帧的连续路径，倾向单镜头。
- **L2VA**：从给定尾帧反推合理开场状态，让动作/物体/构图逐步收敛到尾帧。

## 6. 目标音乐设计字段（确需配乐时的十项写法）

`风格 / BPM（每分钟拍数） / 调性 / 配器架构 / 音乐结构 / 力度变化弧线 / 同步 / 人声 / 制作`，作为创作目标一次性写进 `non_diegetic_music`，音乐全程连续不中断、不分段割裂；不得把音乐写进画面描述。
