## 概念说明

本模块把常见的取证、因果判断、片型选择、提示词格式和角色替换错误汇总为交付检查项。重点是用画面与声音互证，区分真实动作、切镜及后期特效，保证相邻事件和跨段状态连续，并保留原文各项检查的条件、否定、数值与格式要求。

本模块原文中的中文内容完整保留，夹杂的英文自然语言已译为简体中文。字段名、状态名、机位名、路径和模板标签保留原样，含义见词表及正文；提示词示例的译文供理解与审校，需执行英文提示词时请参照原文。本译文不执行任何生成、音视频处理或推理操作。

# 05 — 高频陷阱与交付前验证清单

## 1. 高频陷阱（16 条）

1. **稀疏采样漏关键动作**：掰头、伸手、换人、一次火光可能只有 3–5 帧。稀疏网格只建假设，转折区间必须 8fps 密帧裁决。
2. **拍摄者透明化**：把第一人称拍摄者当纯机位，漏掉只露袖子/车头/手的第三行动者。铁律：有目的运动的非身体物体必有控制者。
3. **BPM（每分钟拍数）误检当配乐**：随机音头会被算法报成稳定 BPM。频谱底鼓网格 + 音头间隔规律性 + RMS（均方根能量）周期性三证，否则判无稳定 BGM（背景音乐）。
4. **后期特效当现场动作**：定格/白闪/漫画线/拟声字/RGB 故障/能量翼进 `editing` 与 `overall_soundscape`，不进现场动作时间线。
5. **先验剧情捕获（最致命）**：用最常见模板收敛后所有证据都被收编成佐证。对策：骨架阶段并列多候选，密帧判别，不选最省事的故事。
6. **水/液体没有来源与方向**：先有蓄力喝，再沿受力方向喷；喷在透明还是镀膜面罩上决定路径，物理不通回查帧。
7. **动作之间中性复位**：相邻动作用残余动量衔接，禁止回中性姿势再开始下一个。
8. **空泛质量词**："高质量/电影感/好看"无法执行，删除或换成可拍的光色材质运动。
9. **角色中段漂移**：subject（主体）锁定 + physics（物理表现）演化 + negative（负面约束）三重固定发色/眼镜/衣物/面罩状态。
10. **换角色顺手改剧情**：时间戳/动作/运镜/剪辑/声音零改动，必要连带改动全部进对照表。
11. **套错相机状态机（本轮首要新坑）**：多镜头快剪（C 型）套进 `HARD LOCK/INSTANT BURST` 会压制必要切镜；编辑式快照（B 型）写成连续运镜会在该静止处漂移。动笔前先按 `06` 分流，C 型用命名机位语法、B 型用两态状态机。
12. **自由散板写 BPM/拍号**：琵琶轮指等自由速度独奏没有节拍器，自相关速度估计低置信度。写 `在 <Audio 1> 的强重音处` + 时间码锚点，不写 BPM/拍数。
13. **有参考图仍堆外貌文字**：图锁外观后再写发型/瞳色/服装会诱导二创。多图只锁身份+服装，环境/灯光/道具由文字；剧情手持武器仍由文字定义。见 `08`。
14. **分段音乐重启 / 用全局时间**：第 2 段音乐必须 CONTINUES（持续延续）不重启；每段时间码从 00:00 重新计，段头标注源片全局区间；段末交接状态要在下段开场复述。
15. **横置误判人物躺/转**：先看地平线与身体的相对关系——地平线一起转是相机滚转（身体不转），地平线水平仅人物转才是真躺/转。
16. **冲击写成连续震动**：连续几下冲击必须逐个可数（位移/前推/旋转微震），明确"不是连续震动、不是随机抖动"，且只动相机、不变形人物。

> 另：枪口火光/爆炸/白闪会被 scene（场景变化）检测误报为切镜，机位连续即同一镜头（见 `07`）；中文/空格源路径先复制为纯英文副本再喂 ffmpeg。

## 2. 认知层自检

- 结论是"像素必然推出"还是"高概率模板"？后者必须找反证。
- 这个动作的发起者是谁？画里那只手/物体受谁控制？
- 换一个剧情/机位假设，这批帧是否同样成立？成立则密帧裁决或提问。
- **片型分流了吗？帧里有没有"运动→完全静止"的台阶？切镜/冲击对齐音头吗？**（决定 A/B/C 状态机）
- **"横过来"是相机滚转还是人物转身？地平线核对了吗？**
- **连续冲击是可数的几下，还是被我写成了"震动"？**
- 音频能量峰、强音头和每个关键动作/切镜是否一一对账？
- 是否把"没看清"误写成"没发生"？

## 3. 交付前验证清单

### 证据层
- [ ] ffprobe 建档完整（时长/画幅/帧率/音轨）
- [ ] 全片稀疏网格已看；每个歧义区间有 4–8fps 密帧；关键瞬间有原分辨率单帧
- [ ] 频谱 + RMS + 音头三检完成；固定节拍/自由散板已判定
- [ ] 每个 RMS 峰有画面成因；每个硬切/定格/冲击/爆发在 ±0.1s 内有 S/H 音头
- [ ] scene（场景变化）检测候选切点已逐一排除火光/爆炸伪切镜，镜头数=真硬切数+1
- [ ] 画外元素（手/袖/车头/道具）已归并到行动者并登记入画时间
- [ ] 单通道证据已标推测或已提问

### 剧情与机位层
- [ ] 每事件有触发→动作→反应，相邻事件残余动量衔接
- [ ] **片型已分流（A连续/B快照/C快剪），所用相机机制与片型一致**
- [ ] **机位分镜表完整（景别·机位角度·运镜·动机）；C 型机位已命名、切镜挂音头；B 型 LOCK/BURST 互斥、静态禁令三处重复**
- [ ] 液体/面罩/杯瓶/头发干湿有完整状态演化
- [ ] N 拍重复结构已提炼进 editing（剪辑字段）；每个定格四要素齐全，定格外无特效残留

### H3 格式层
- [ ] 字段名与顺序符合 02 号文件（Ref2VA 符合 shot-syntax 的镜头语法六段式），无自创字段
- [ ] `[Shot 1]` 无时间戳，其后严格递增且只标状态变化；Ref2VA 两位小数；分段每段从 00:00 起
- [ ] 三层声音不串；无 BGM 时明确写静音 / N/A（不适用）；散板不写 BPM
- [ ] 每个运镜写了动机，negative（负面约束）列了禁用运镜与风格
- [ ] 提示词本体全英文，无中文残留
- [ ] I2VA：有锚定句与 visual_anchor（视觉锚点），省略环境/灯光文本；标签语义全文一致
- [ ] 时长与 ffprobe 误差 ±0.02
- [ ] 对话/歌词用 `<d>[Language] 正文</d>`；不写受版权保护的歌词/商标

### 多图与分段附加
- [ ] 图1/图2 各锁一个角色的身份+服装，正文零外貌文字；环境/灯光/剧情手持道具由文字
- [ ] 每段 ≤约15s，切点在气口；每段重复图权威/机位状态机/环境/negative（负面约束），可独立成片
- [ ] 每段音乐 fully_copy（完整复制）且 CONTINUES（持续延续）不重启；音头已换算为段内时间
- [ ] 上段末交接状态 ＝ 下段 [Shot 1] 开场状态；跨段身份/服装/道具/方位不漂移

### 换角色附加
- [ ] 冻结层与底本逐字一致（随机抽 3 时间戳比对）
- [ ] 只改 subject（主体描述） / physics（物理表现） / 被带到的服装词
- [ ] 动作兼容性问题已处理；专属道具按入画纪律分级
- [ ] 动漫造型已转真人角色扮演；替换对照表完整、连带改动已声明

## 4. 交付形态

1. 中文反推报告（片型分流/场景/人物/因果链/机位分镜/剪辑特效/节奏卡点/声音结论/推测项）
2. 英文 H3 完整提示词（代码块，便于整段复制；长片逐段给）
3. 换角色附中文对照表
4. 默认在回复中打印最终文本块；仅当用户或工作流明确要求时存盘 `<video-stem>_h3_prompt.md`
5. 说明可选增强（I2VA 首帧锁定、定格关键帧导出、配乐字段替换），不擅自叠加
