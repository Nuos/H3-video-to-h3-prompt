## 概念说明

本模块用密帧中的构图变化及音频中的音头，将影片分为一镜到底、编辑式快照和多镜头快剪。三种片型分别采用连续机位、锁定与爆发互斥状态、命名机位选择规则。关键在于精确规定相机何时运动、何时完全静止，以及切镜和冲击如何与声音对齐，避免把相机滚转误认为人物旋转。

本模块原文中的中文内容完整保留，夹杂的英文自然语言已译为简体中文。字段名、状态名、机位名、路径和模板标签保留原样，含义见词表及正文；提示词示例的译文供理解与审校，需执行英文提示词时请参照原文。本译文不执行任何生成、音视频处理或推理操作。

## 完整正文译文

# 06 — 片型分流与相机状态机（连续运镜 / 编辑式快照 / 多镜头快剪）

取证做完、动笔写 H3 之前，**先判片型再选状态机**。同一段"镜头很快、很有冲击力"的画面，可能是三种完全不同的机制，套错状态机是反推提示词失败的首要原因——把多镜头快剪套进"硬锁/爆发"两态，会错误压制必要的切镜；把编辑式快照写成连续运镜，模型就会在该静止的地方漂移。

---

## 0. 六条可复用检查清单（每次反推先过一遍）

1. **先判「连续运镜」还是「离散快切」**：对转折段用 8fps 以上密帧，别让稀疏采样跨过整个爆发段；在帧序列里找「运动 — 完全静止」的**台阶**。有台阶＝离散编辑；全程连续位移＝运镜。
2. **音频做时间轴对账**：每个切换 / 定格 / 冲击是否挂在节拍音头上（用 `scripts/onset_probe.py`）？**是 → 编辑式快照/卡点剪辑**；否 → 才考虑自由运镜。
3. **有参考图就别写外貌**：图锁外观（脸、发型、服装、配饰），文字只写相机 / 时间 / 状态机 / 环境道具。外貌文字与图并用会诱导模型重设计。
4. **静态与爆发写成两个互斥状态**：静态段把「不许慢动作 / 漂移 / 继续运动 / 残留动量」反复写死（在时间轴、相机规则、negative（负面约束）多处重复）。
5. **横置先怀疑相机滚转**：画面"人物躺了/横了"时，先看**地平线与身体的相对关系**——地平线一起转＝相机滚转，身体没转；地平线水平、只有人物转＝人物真的躺/转。别轻易判定人物躺下。
6. **冲击要可数、不可糊**：连续三下冲击必须分别可读（如 IMPACT1 位移 / IMPACT2 前推 / IMPACT3 旋转微震），明确写「不是连续震动、不是随机抖动」，且**只动相机、不变形人物**。

## 1. 三型分流决策表

| 判据（密帧 + 音头对账） | 片型 | 相机机制怎么写 |
|---|---|---|
| 全程一条连续机位，景别靠手持/推拉变化，无构图台阶；可有定格笑点 | **A 一镜到底（连续拍摄）** | 一条手持/锁定基线 + 每次运镜的动机；定格作为同镜头内事件（见 `03-edit-effects.md`） |
| 画面由**离散的静态构图**组成，构图之间是极短爆发，静态段相机**绝对零运动**；切换/冲击精确挂音头 | **B 编辑式快照** | 两态互斥状态机 `HARD LOCK ↔ INSTANT BURST`（见 §3） |
| 多个机位/景别/角度**硬切正反打**，每个镜头有自己的机位，切镜挂乐句重音；无单一长镜 | **C 多镜头快剪（多镜头蒙太奇）** | **命名机位语法** + 切镜纪律（见 §4），**不要**套两态 LOCK/BURST |

混合型按主导机制归类，少数异类镜头单独标注（例：多镜头快剪片里夹一个一镜到底的环绕长镜，或结尾转一个近锁定长镜）。

---

## 2. A 型 — 一镜到底（连续拍摄）

判据：帧图表上构图连续演变、无角度/景别跳变；`blend=difference` 相邻帧是平滑渐变而非整帧翻转。

写法要点：
- 开头定基线机位（POV（主观视角） / 第三人称、景别、角度、手持幅度）；
- 每次运镜给 `类型 + 幅度 + 速度 + 动机`（什么身体动作/事件触发）；
- 明确 `一个不间断的长镜头，无硬切，无叠化，无速度渐变`；
- 定格/白闪/漫画笑点是同镜头内的 `FREEZE-FRAME GAG n`（第 n 个定格笑点），不是切镜（见 `03-edit-effects.md`）；
- 多数恶作剧/UGC（用户生成内容）反转属此型。

---

## 3. B 型 — 编辑式快照：两态互斥状态机

判据：帧序列里反复出现「极短高速重构图 → 立刻完全静止并保持」的台阶；每个台阶边界对齐音头。代表作是身体部位逐级揭示（脚→膝→上身→脸）一类的快速切换后锁定剪辑。

### 3.1 显式定义两个互斥状态（开头命名，全文复用）

```text
相机只在以下两个状态之间交替，绝不混合：
STATE A — HARD LOCK（完全锁定）：相机 = 绝对零运动。不得有平移、变焦、前推、
后拉、水平摇摄、俯仰摇摄、环绕、滚转、漂移、视差、手持运动、微震或
残余动量。构图应像一张静止照片一样保持在屏幕上。
STATE B — INSTANT BURST（瞬时爆发）：相机运动只能发生在具名的爆发时间区间内；
运动立即开始，速度极快，立即结束，并带有强烈的定向
运动模糊。不缓入，不缓出，不做平滑插值。在
每次爆发结束的准确时刻，相机 = 零运动。
绝不混合两种状态；绝不以连续插值穿过静态区间。
```

### 3.2 静态段把禁令反复写死（清单第 4 条）

每个静态时间块都重复一遍 `禁止变焦 / 前推 / 后拉 / 水平摇摄 / 俯仰摇摄 / 漂移 / 视差 / 手持运动 / 微震 / 残余运动`，并在 `camera_direction` 与 `negative_constraints` 再各写一次。长提示词后半模型会弱化早期约束，**同一规则多处重复是故意的，不是啰嗦**。

### 3.3 可数冲击（清单第 6 条）

爆发收尾若有三下冲击，逐个命名、互不混淆：

```text
三下独立可辨的相机冲击（不是连续震动，不是随机抖动）：
IMPACT 1 — 一次短促、微小的位置震动；
IMPACT 2 — 一次短促的向前放大冲击；
IMPACT 3 — 一次短促的旋转微震。
节奏：砰 → 砰 → 砰 → LOCK（锁定）。
只有相机承受冲击；不要使脸部、头部或身体变形。
```

### 3.4 横置/滚转纪律（清单第 5 条）

- 需要"画面横过来"时写清楚是**相机滚转**：`人物不旋转，身体不扭转；横置效果仅由相机朝向产生`。
- 中段若要持续倾斜，写成一条持续规则（`在 KNEE（膝部）→...→NECK（颈部）的整个过程中保持倾斜地平线；不要调平，不要反向滚转，不要交替倾斜`），最终滚转只在结尾预留一次。

### 3.5 时间块与对账

- 每个 LOCK / BURST 给精确毫秒区间（`00:00.120–00:00.420 STATIC HERO 01`），块边界即音头；
- 结尾给一张**时间预算总表**（逐块起点–终点 + 状态）+ 一张 NEGATIVE（负面约束）大清单 + 一句话最终观感（`PICTURE（静态画面）→SNAP（迅猛切换）→...→LOCK（锁定）`）。

## 4. C 型 — 多镜头快剪（多镜头蒙太奇）：命名机位语法

判据：硬切正反打、机位/角度在镜头间跳变（攻击者正面、被击者背面/俯拍等），切镜挂乐句重音；单个镜头内部可能手持运动，但**不存在跨镜头的单一连续相机旅程**。代表作：战斗/动作恶搞、MV（音乐视频）式快剪。

**关键：不要套 HARD LOCK / INSTANT BURST**——那会把必要的切镜当成"泄漏运动"压掉。C 型的"状态机"是**机位选择规则**。

### 4.1 先命名全片反复出现的机位（具名机位）

在开头定义一套具名机位，规定每个叙事拍用哪个、角度景别、表达什么，禁止混用。例（战斗恶搞片）：

```text
GUNNER SHOT : 正面，相机略低于视线高度，中景/近景，枪口朝向镜头（攻击者视角）——强势。
BUTT SHOT   : 极低的后方机位，相机靠近地面、位于臀部高度，从受击者后方仰拍，受击区域居中——肢体闹剧效果。
PRONE SHOT  : 受击者倒在地面时，以高机位自上向下俯拍（~50°）——弱势。
WIDE SHOCK  : 用锁定的正面/低机位广角镜头拍摄光束和爆炸，将动作容纳在稳定画框中。
CLOSE INSERT: 紧凑的俯拍 / 面部 / 道具特写。
ORBIT SHOT  : 一个连续的低角度手持弧形运镜，绕主体环行（正面/背面交替）。
STINGER CLOSE-UP : 紧凑的后方过肩特写，相机近乎锁定，仅极缓慢前推，背景转为焦外虚化——表现回头/凝视。
每个叙事拍只使用指定机位；绝不混用或自行添加运镜。
```

### 4.2 机位编码权力关系与情绪

仰拍攻击者 / 俯拍或贴地仰拍被击者，是在用角度写强弱与喜剧；一个"帅气正面机位"紧接"狼狈俯拍/贴地机位"就是笑点机关。把这种**角度反差剪辑**显式写进 `camera_direction`，而不只是罗列景别。

### 4.3 切镜纪律（写进 editing（剪辑字段））

- 切镜只在有意义的视觉变化（新机位/空间关系/运动状态/能量级/表演重点）时发生，并落在乐句重音的音头上；
- `动作匹配剪辑`：跨切点保持运动方向、速度、身体焦点、手势轨迹、视觉动量；
- 枪口火光 / 爆炸闪光**不是切镜**（见 `07` 的火光伪切镜）；
- 动静对比要写明：前段密集快切，某点之后**骤收成一个近锁定长镜**（如慢回头怒视），快→慢本身就是节奏设计。

### 4.4 每个 [Shot] 句首前置机位

每个镜头描述先给 `机位名 + 景别 + 角度`，再给动作与同期声（六要素见 `shot-syntax.md`）。相机规则段再按时间码复述"哪一拍用哪个机位"，与时间轴互锁。

## 5. 反幻觉骨架：为什么"有效提示词"能一次跑通（七要素）

无论 B 型还是 C 型，高命中提示词共享同一套反幻觉结构：

1. **置顶权威声明**：图=唯一身份/服装来源；音频=唯一时间/节奏来源；（环境道具若由文字定义，也在此声明边界）。禁止自创节奏、禁止替换音频。
2. **显式状态机**：B 型命名 LOCK/BURST 两态；C 型命名机位集合。互斥、不混合、全文复用同一命名。
3. **精确时间块**：毫秒/0.1s 级，块边界对齐音头；时间戳只标真实状态变化。
4. **相机绝对化**：把所有禁止项列全（变焦/水平摇摄/俯仰摇摄/漂移/视差/手持运动/环绕/慢动作…），并说明唯一允许的例外。
5. **同一规则多处重复**：时间轴、相机规则、negative（负面约束）各写一遍，防长提示词后半被弱化。
6. **零外貌文字**（有参考图时）：身份服装全归图，词元预算投给相机/时间/状态机；剧情手持道具（武器等）仍由文字定义。
7. **结尾三件套**：时间预算总表 + NEGATIVE（负面约束）大清单 + 一句话最终观感。

## 6. 分流自检（动笔前 30 秒）

- [ ] 密帧里有没有"运动→完全静止"的台阶？（有→倾向 B；全程连续→A；机位跳变→C）
