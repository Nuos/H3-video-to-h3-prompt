## 概念说明

本模块先判断音轨实际包含音乐、现场声还是短促音效，再依据响度给出音乐与整体声景的提示词写法。叙事内声音（diegetic sound）指故事场景中有声源的声音，例如脚步、说话和现场环境声；叙事外音乐（non-diegetic music）指为观众添加、通常不来自场景内部声源的配乐。RMS 包络用于观察声音能量随时间的变化，BPM 数值必须结合节拍规律和频谱图共同判断。

下文保留全部命令、字段、路径和结构性占位符。`<d>` 是对白标签，`[Language]` 表示语言占位符，`<type>` 表示场所类型占位符，`<Subject 1>` 表示主体占位符。提示词模板的中文译文用于理解；若需复用原始英文提示词，可参考链接中的原文。

# H3 提示词的音频启发式分析

音频分析分为两层：**（A）取证式分类**——音轨究竟是否包含音乐，其能量峰值又出现在何处；**（B）响度 → 写法映射**——确认存在音乐时，如何填写 `non_diegetic_music`。先执行 A，再执行 B；如果音轨实际上只有现场声，就不要为它编写音乐描述。

## A. 取证式分类（先做这一步）

### A1. 声谱图——音乐与现场声的区分

```powershell
ffmpeg -y -i "IN.mp4" -vn -ac 1 -ar 22050 audio.wav
ffmpeg -y -i audio.wav -lavfi showspectrumpic=s=1000x400:legend=1 spectrum.jpg
```

- 间距均匀、贯穿整个片段的低频竖条 → 鼓机／节拍，说明存在音乐。
- 宽频带的随机能量，偶尔出现上升的谐波弧线（≈800Hz→3kHz）→ 人声说话／笑声／喊声。
- 持续存在、覆盖全频段的低电平声底 → 环境声底层（街道、风、引擎）。
- 定格／喷溅时刻出现明亮的竖柱 → 瞬态音效；将其与画面事件对齐。

### A2. 0.5s RMS 包络 + BPM 可信度

```powershell
python scripts/audio_probe.py audio.wav
```

标出每一个 RMS 峰值，并找出与之对应的画面原因（参见 `01-forensics-commands.md` 中的矩阵）。只有以下条件全部成立时，BPM 读数才可信：

1. `onset std / onset mean < 0.8`（节拍有规律）；
2. 声谱图呈现有规律的底鼓网格；
3. RMS 呈周期性升降，而非出现孤立尖峰。

否则，BPM 就是把随机瞬态误判成了节拍 → 得出结论：**没有稳定的背景音乐，只有叙事内现场声**，并将 `non_diegetic_music` 设为明确静音／`N/A`。

### A3. 对白、音乐与环境声的区分（无法听音时）

- **可见的说话行为**（张嘴、做手势、能看到麦克风）→ 对白；在时间线内用 `<d>[Language] 文本</d>` 包裹，音乐保持低音量或设为 `N/A`。
- **同步舞蹈／协调一致的动作** → 预期存在音乐；在 `non_diegetic_music` 中描述。
- **空场景／对镜讲话／安静的恶作剧** → 环境声，最多加少量轻柔的衬底配乐。
- 画外伸入的手臂与人物互动，同时只有孤立的 RMS 尖峰、没有底鼓网格 → 现场声（倾倒、喷溅、呛咳、笑声），不是音乐。

## B. 响度 → 写法映射（volumedetect）

```powershell
ffmpeg -y -i "IN.mp4" -vn -ac 1 -ar 8000 -f wav out8k.wav
ffmpeg -i out8k.wav -af "volumedetect" -f null NUL 2>&1 | Select-String volume   # PowerShell
# bash: ffmpeg -i out8k.wav -af volumedetect -f null - 2>&1 | grep volume
```

| 指标 | 含义 |
|---|---|
| `mean_volume` | 整条音轨的平均响度 |
| `max_volume` | 瞬态峰值——高于 -3 dB 时存在削波风险 |

| mean_volume | max_volume | 可能的内容 | `non_diegetic_music` 写法 |
|---|---|---|---|
| -8 至 -12 dB | 0 至 -2 dB | 高音量俱乐部音乐／电子音乐／电子舞曲 | `一段节奏快速、充满活力的电子音乐，带有厚重的底鼓、多层合成器主旋律，以及经过侧链处理的贝斯。` |
| -10 至 -15 dB | -1 至 -3 dB | 流行乐／舞曲流行乐／韩国流行乐 | `一段明亮、中等速度的流行音乐，带有合成器主旋律、每拍一次的四拍底鼓和明快的拍手声。` |
| -13 至 -17 dB | -3 至 -6 dB | 动漫音乐／芯片音乐／可爱风流行乐 | `一段明亮的日式动漫舞曲流行音乐，速度适中，带有跳跃的合成器主旋律、每拍一次的四拍底鼓，以及可爱的芯片音乐装饰乐句。` |
| -16 至 -20 dB | -5 至 -8 dB | 现场演出／餐厅／咖啡馆视频日志 | `一段温暖的轻流行伴奏，节奏舒缓，带有柔和的木吉他琶音、轻轻的鼓刷军鼓声，以及含蓄的钢琴主旋律。` |
| -20 至 -25 dB | -8 至 -12 dB | 电影配乐／衬底配乐 | `一段克制、缓慢的管弦乐配乐，以持续的低音弦乐为主，没有渐强起伏。` |
| -25 至 -35 dB | -12 至 -18 dB | 氛围持续音／自然环境 | `安静的氛围持续音，带有轻柔的场地底噪，没有旋律发展。` |
| < -35 dB | < -18 dB | 接近静音 | `N/A` |

## overall_soundscape 写法

| 场所 | 模板 |
|---|---|
| 室内餐厅／咖啡馆 | `柔和的室内 <type> 环境声充满空间：微弱的吊扇嗡鸣、邻桌传来的低沉餐具碰撞声，以及厨房远处一声短促的喊声。` |
| 城市户外夜景 | `持续的夜间小巷环境声：远处交通的低鸣、微弱的踏板摩托车怠速振动声，以及潮湿路面的场地底噪。` |
| 音乐会／俱乐部 | `现场演出的环境声，音乐之下伴有轻柔的人群低语。` |
| 安静房间 | `安静的房间底噪，带有轻微的环境细节声。` |
| 森林／自然环境 | `鸟鸣与轻柔的微风声穿过树叶传来。` |

为每一个可见动作添加一项**叙事内动作声**：

| 可见动作 | 添加这一行 |
|---|---|
| 将液体倒在脚／地面上 | `可听见倒水声，一片深色湿痕逐渐扩散` |
| 液体击中塑料面罩 | `一声湿润的啪嗒声伴着液体在塑料面罩上迸溅开来` |
| 旋转／转身 | `<Subject 1> 转身时，服装面料轻轻沙沙作响` |
| 在湿地面上行走 | `脚跟下传来轻柔的踩水声` |
| 喝一口后呛到 | `呛咳着将水咳喷出去，水从嘴唇间喷出` |
| 定格笑料 | `唱片刮擦尖声 → 强劲的撞击音 → 半秒接近静音 → 环境声骤然恢复`（参见 `03-edit-effects.md`） |

## 当源片无声／只有现场声时

设置 `non_diegetic_music: N/A`（14 字段写法：`没有叙事外音乐。音乐层全程明确保持静音；声轨只有叙事内现场声，以及定格喜剧音效的撞击声。`），并将所有声音细节都放入 `overall_soundscape`。

## 禁止事项

- 不要写出歌曲、艺人或受版权保护的配乐名称；不要转写歌词。
- 不要在同一个块中混写音乐与环境声；让它们各自放在对应字段中。
- 不要将音乐写得比原片更响——H3 会自动提高音量。
- 未经 A2 中的三项条件核验，不要相信 BPM 数值。
