## 概念说明

本模块规定 Ref2VA 提示词的六部分骨架、单镜头必须包含的六项信息、切镜时间与过渡动词、运镜描述、主体位置连续性以及参考标签的用法。取证过程负责获得内容，本模块负责把内容写入对应字段。

下文提示词及占位说明中的自然语言已完整译为中文，供理解和改写；执行时可对照原文。字段、枚举值、素材和镜头标签、事件标识符以及时间码保持原样。原文的“两位小数”规则与多个三位小数示例不一致，译文按原样保留，在审校记录中标注。

# H3 Ref2VA 镜头语法参考

`detailed_description` 部分的简明框架。填写任何 Ref2VA 提示词（视频 + 一张或多张参考图像/一段或多段参考视频或音频）时，可复用此框架。对于 T2VA / I2VA / FL2VA / L2VA，请使用 `02-h3-field-mapping.md` 中的 14 字段模板。用于*产出*这些内容的取证工作流（密集采样、音频交叉验证、因果事件链、定格笑点）位于 `SKILL.md` 和 `01-forensics-commands.md`；本文件规定如何将这些内容写入 Ref2VA 字段。

## 六部分框架

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的<身份>，具有<外貌特征列表>。
<Video 1> 是定义目标视频镜头结构、运动路径与节奏的源视频：<一句话的源视频描述>。<Video 1> 仅用于时间结构；<舍弃的内容>。

summary:
[<任务标签> + <素材标签>] <使用 <Subject 1>、<Picture 1>、<Video 1> 的一段式任务摘要>。

retention_analysis:
<Subject 1>（出现在 [Shot X] 等镜头中）：<fully_preserved | partially_preserved | transferred | reused> - <保留的内容>。
<Video 1>（约束整段视频）：reference - <保留的时间/结构线索>；<舍弃的内容>。
[为每个其他参考素材增加一行]

detailed_description:
目标视频采用<一句话的风格描述>。

[Shot 1] <包含 6 项要素的构图描述（见下文）>。

[Shot 2] 在 00:XX.XXX，<过渡动词><包含 6 项要素的其余镜头描述>。

overall_soundscape:
<贯穿整段视频的环境氛围声 + 物理音效 + 非语言人声；定格时的后期音效归于此处>。

non_diegetic_music:
<仅供观众听见的配乐：乐器编配 + 音乐速度 + 力度变化> | N/A
```

## 每个镜头的六项要素

每个 `[Shot N]` 块都必须覆盖全部六项。遗漏其中一项，是 H3 凭空生成内容最常见的原因。

| # | 要素 | 模板 |
|---|---|---|
| 1 | 构图 | `一个全景镜头` / `一个中近景镜头` / `一个紧特写镜头` / `一个过肩镜头` |
| 2 | 主体外貌 + 位置 | `<Subject 1>，具有<关键特征>的<身份>，<位置短语>` |
| 3 | 环境 + 灯光 | `<场景>，具有<光源 + 光质 + 光线方向>` |
| 4 | 动作 + 状态变化 | `<Subject 1> <以现在时描述的动作>……<可见的状态变化>`（触发 → 动作 → 结果，嵌入叙事世界内的声音） |
| 5 | 摄影机运动 | `摄影机以小幅度、低速向前推进` / `保持稳定` / `向后拉远` |
| 6 | 当前声音 | `<简短的拟声或描述性声音提示>` |

## 切镜语法（仅适用于多镜头）

```
[Shot 1]                            <- 无时间戳
[Shot 2] 在 00:03.200，……          <- 第一次切镜，时间严格递增
[Shot 3] 在 00:06.400，……
[Shot N] 在 00:11.700，……
```

规则：

- 始终使用两位小数，以英文句点作为小数分隔符。
- 禁止在 `[Shot 1]` 上写 `0.00`——`[Shot 1]` 是唯一没有时间戳的镜头。
- 每个切镜时间必须**严格大于前一个时间**，并且**小于或等于 `duration`**。
- 最后一个镜头默认在 `duration` 时结束，无需重复标明。
- 定格笑点不是切镜：将其保留在同一镜头内，作为 `FREEZE-FRAME GAG n` 事件，并写明入点、持续时间和瞬间恢复（见 `03-edit-effects.md`）。

## 过渡动词库

每次切镜选择一种，不要混用：

| 动词 | 何时使用 |
|---|---|
| `摄影机切到` | 普通硬切（默认） |
| `镜头过渡到` | 柔和切换、淡入淡出、叠化 |
| `视野转向` | 同一摄影机，改变焦距或角度 |
| `一次硬切展现出` | 以硬切切入刻意不同的场面状态 |
| `角度切换到` | 快速变换角度，同时保持主体连续性 |

## 单镜头视频（不切镜）

```
[Shot 1] <初始构图>。

<Subject 1> <第一个动作>。在 00:01.200 <Subject 1> <下一个动作>。
在 00:02.500 <Subject 1> <下一个动作>。……
```

在单个 `[Shot 1]` 块内部，用 `在 00:XX.XXX` 从句标明每个表情动作或节奏点的时间。大多数恶作剧/用户生成内容中的反转，都是带定格笑点的单镜头，而非多次切镜。

## 摄影机运动词汇

- `摄影机以小幅度、低速向前推进`——轻缓的向前移摄
- `摄影机以中等幅度、中等速度向前推进`——明显的移摄
- `摄影机以小幅度、低速向后拉远`——轻缓的向后移摄
- `摄影机以小幅度、低速向右平移`——横向滑移
- `摄影机保持稳定`——固定机位
- `摄影机以小幅度、低速向右摇摄`——水平旋转
- `摄影机以小幅度、中等速度向下/向上摇摄`——垂直旋转
- 手持第一人称：`全程保持轻微自然的手持晃动，绝不呈现稳定器般的平滑感`

始终量化幅度（无 / 小 / 中 / 大）与速度（慢 / 中等 / 快），并说明每次运动的动机。

## 主体开场句式

为保持每次切镜的连续性，新镜头开头应复述主体最近一次已知的位置：

```
[Shot 2] 在 00:03.200，摄影机切到 <Subject 1> 的紧特写，
他/她仍坐在第 1 镜头中的桌边，碗和勺子仍在画面中。
```

## 参考标签规范

为每一项可复用内容选择正确标签：

| 标签 | 用途 |
|---|---|
| `<Subject N>` | 可复用的可见内容（人物、动物、物体、场景、风格、动作） |
| `<Picture N>` | 用作帧锚点、关键帧、尾帧或构图参考的图像 |
| `<Video N>` | 提供剪辑源素材、续接依据或整段视频结构的参考视频 |
| `<Audio N>` | 用于复制或参考人声 / 音乐 / 环境氛围声的音频信号 |

标签一经指定，在每个部分都必须表示**同一事物**。改名、使用别名或隐式复用，都属于严重错误。

## “通用 Picture 1”变体

当一张参考图同时定义角色与场景时，使用：

```
<Picture 1> 是整个目标视频的通用视觉锚点。它不仅定义 <Subject 1> 的外貌、服装、头发和配饰，还定义场景的构图布局、摄影机角度、灯光方向、色彩方案、道具摆放和背景环境。每当目标视频需要确定房间、道具、窗边光线、墙面色调或周围氛围的样子时，都必须遵循 <Picture 1>。
```

将保留关系标记为 `（约束整个视觉外观）`，并以 `按 <Picture 1> 定义的方式构图和布光` 开启镜头描述。
